# Über das Projekt

## Dieses Projekt wurde im Jahr 2025 im Rahmen des Moduls 294 entwickelt, um die Grundlagen von JavaScript zu erlernen und praktisch anzuwenden.

## The Escape Prank ist ein kleines, interaktives Puzzle-Spiel, bei dem es darum geht, die Einstellungen der Webseite zu erreichen. Dabei müssen knifflige Hindernisse überwunden und kreative Lösungen gefunden werden.
